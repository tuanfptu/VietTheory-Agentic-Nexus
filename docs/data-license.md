# Data Rights and Distribution

The project owner has confirmed that permission was obtained from the lecturer to use,
publish, and redistribute the five source textbook PDFs included in the project corpus.

This authorization applies to the source documents; it does not automatically define
the software license for VietTheory-RAG. Source code and document licensing must remain
separate in repository and release metadata.

Before a public release, the project owner should retain the original written permission
and complete the following record:

- permission grantor and role;
- date permission was granted;
- covered document titles or filenames;
- allowed channels, such as GitHub, demo hosting, or dataset distribution;
- attribution wording or other conditions;
- whether derivative extraction and OCR artifacts may also be redistributed.

Until release packaging is selected, PDFs remain excluded from normal Git history to
avoid unnecessary repository growth. Git LFS or a separate versioned dataset/release is
preferred for distribution.
